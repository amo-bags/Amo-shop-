# متجر عطور مجاني + طلبات WhatsApp

هذا قالب متجر مجاني بالكامل يعمل بدون قاعدة بيانات وبدون دومين مدفوع.

## التشغيل
افتح `index.html` في المتصفح.

## رفعه مجاناً
يمكن رفع الملفات إلى GitHub ثم تفعيل GitHub Pages.

## أهم تعديل
افتح `script.js` وغير:
WHATSAPP_NUMBER = "9627XXXXXXXX";
إلى رقم WhatsApp الحقيقي بدون + أو مسافات.

## إضافة صور المنتجات
داخل مصفوفة products في `script.js` غيّر:
image:""
إلى مسار الصورة، مثال:
image:"images/perfume1.jpg"

ضع الصور داخل مجلد `images`.

## ملاحظات
- لا توجد بوابة دفع.
- الطلب يتم تجهيزه وإرساله مباشرة إلى WhatsApp.
- الأسعار والمنتجات قابلة للتعديل من `script.js`.
